### 📌 Project Overview
This lab combines two important intermediate skills:

- Data Cleaning & Standardization  
- Min/Max Analysis (Top Performers)

The goal is to prepare clean data and identify extreme values (highest sales, discounts, etc.) from the D-Mart retail dataset.

## 🧹 Part 1: Data Cleaning & Standardization

### What was done
- Created clean **Update_** columns for:
  - Region
  - Category
  - Sales
  - Customer Type
  - Payment Mode
  - City
- Standardized Payment Mode to uppercase (`CARD`, `CASH`, `UPI`)
- Applied consistent formatting and capitalization
- Applied **Conditional Formatting** to highlight key values
- Prepared the dataset for further analysis

### Skills Demonstrated
- Data Cleaning best practices
- Text standardization
- Structured References
- Conditional Formatting
- Creating analysis-ready datasets

### How to Explore
1. Open `ExcelLab4.xlsx`
2. Compare original columns with the new `Update_` columns
3. Notice Payment Mode is consistently formatted (CARD, CASH, UPI)
4. Apply filters on any `Update_` column
5. Observe Conditional Formatting applied on important values

---

## 📈 Part 2: Min/Max Analysis (Top Performers)

### What was done
- Identified records with the **highest sales** (close to ₹4,999)
- Created a focused view of top-performing transactions
- Analyzed Min and Max Discount values
- Highlighted extreme values for better business insights

### Key Observations
- Highest sales records are in the range of **₹4,998 – ₹4,999**
- Top sales are spread across different regions and categories
- Useful for identifying high-value transactions

### Skills Demonstrated
- Sorting & Filtering
- Min / Max analysis
- Identifying outliers and top performers
- Conditional highlighting of extreme values

### How to Explore
1. Open `ExcelLab5.xlsx`
2. Go to the **Min Max Discount** sheet
3. Review the top sales records (highest values)
4. Compare these high-value transactions with the full dataset
