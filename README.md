### 📌 Project Overview
Real-world datasets are rarely analysis-ready. This lab focuses on systematic **data cleaning and standardization** techniques that every data analyst must master.

### ✨ Cleaning Tasks Completed
- Standardized Region, Category, Customer Type, Payment Mode, and City
- Created clean “Update_” columns
- Applied consistent capitalization and formatting
- Prepared the dataset for filtering, conditional analysis, and PivotTables

### 🛠️ Skills Demonstrated
- Data Cleaning best practices
- Text standardization
- Structured References
- Creating analysis-ready datasets

### 🔍 How to Explore
1. Open the workbook
2. Compare original columns with the new `Update_` columns
3. Observe that Payment Mode is now consistently formatted (CARD, CASH, UPI)
4. Apply filters on any `Update_` column to view clean unique values
